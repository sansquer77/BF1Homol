# Glossário BF1

> [!info] Status
> **implementado** · área: `bf1` · atualizado em 2026-07-31 · relacionados: [[02_regras_de_negocio]], [[03_spec]], [[specs/classificacao]]

## Termos

| Termo | Definição canônica |
|---|---|
| Aposta automática | Aposta criada pelo sistema após ausência do participante, sujeita à penalidade configurada. |
| Bônus Campeão | Pontuação por acertar o campeão de pilotos. |
| Bônus Equipe | Pontuação por acertar a equipe campeã. |
| Bônus Vice | Pontuação por acertar o vice-campeão de pilotos. |
| Descarte | Menor pontuação elegível removida quando a regra da temporada está ativa. |
| Prova realizada | Prova que possui resultado cadastrado e pode participar da pontuação e do descarte. |
| Total Geral | Soma dos pontos de todas as provas realizadas, antes de bônus e descarte. |
| Total Válido | Total Geral mais os três bônus de campeonato, menos o descarte. Base da posição e diferença. |
| Ficha | Peso atribuído a um piloto na aposta de uma prova. |
| JTI | Identificador único de uma sessão JWT revogável. |
| Master | Perfil com controle integral do sistema. |
| Deadline | Instante limite canônico após o qual determinada aposta é bloqueada. |
| Aposta de campeonato | Palpites de campeão, vice e equipe para uma temporada. |
| Temporada | Ano lógico que agrupa provas, apostas, regras e classificação. |
